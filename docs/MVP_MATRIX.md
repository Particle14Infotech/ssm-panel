## Deferred Features (Hidden Behind Feature Flags)

These features remain implemented or architected in code, but are hidden from UI and excluded from the MVP demo scope:
1. **Public Reseller Portal & API** (`RESELLER_FEATURE_FLAG=false`): Backend controller and service exist in `apps/api/src/modules/reseller`, but public nav routes are deferred.
2. **Two-Factor Authentication (TOTP 2FA)** (`TWO_FACTOR_FEATURE_FLAG=false`): Logic present in `auth.service.ts`, UI onboarding deferred.
3. **SMS / WhatsApp Gateway Notifications** (`SMS_NOTIFICATIONS_FLAG=false`): In-app notifications and console SMTP active.
4. **Data Archival Background Job** (`DATA_ARCHIVAL_FLAG=false`): Database remains live without cold S3 offload.
5. **OpenTelemetry Telemetry Pipeline** (`OTEL_FLAG=false`): Pino structured logging with request ID tracking active.
