# 🧠 Feature Brain: 07 - Frontend 3D & UI Stage

## 1. Quick Summary
Manages the persistent 3D glass crown stage and design system on the landing page and marketing layout.

## 2. Key Files
- **3D Crown Component:** `apps/web/components/three/CrownStage.tsx`
  - Fixed full-screen Three.js Canvas (`pointer-events-none`, `z-0`).
  - GSAP ScrollTrigger coupling to sections (`data-crown="right | center | left"`).
  - Rotation restricted to Y-axis with 17° fixed downward tilt (`rotation.x = 0.30`).
  - Bloom pass on desktop only (`UnrealBloomPass`, intensity 0.9, threshold 0.25).
- **GLTF Crown Model:** `apps/web/components/three/objects/CrownModel.tsx`
  - Loads `/models/crown.glb` via `useGLTF`.
  - Replaces materials:
    - `glass`: `MeshPhysicalMaterial` (#DBEF90, opacity 0.5, flatShading).
    - `core`: `MeshStandardMaterial` (#0b1200, emissive #243100).
    - `edges`: `LineBasicMaterial` (#DBEF90, additive blending).
  - 8 glowing emissive tip spheres at $r = 1.05, y = 0.5, \text{angle} = k \times 45^\circ$.
- **Fallbacks:**
  - `apps/web/components/motion/useMotionPreference.ts`:
  - Automatically switches to static `/brand/crown@2x.webp` when `< 768px` or `prefers-reduced-motion: reduce`.
