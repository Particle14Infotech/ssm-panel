# audit-first
Read and plan before changing anything.
1. Restate the task and write its acceptance criteria as a numbered list.
2. List the files and docs you need, then open them. Do not rely on memory.
3. For each thing the task depends on, report: exists / partial / missing, with file path.
4. Write a plan of at most 5 lines. If it touches more than 5 files or any money, auth or migration code, stop and wait for my OK.
5. List assumptions and unknowns. Ask at most one blocking question.
