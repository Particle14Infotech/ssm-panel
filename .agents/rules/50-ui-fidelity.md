# UI fidelity

- Match the matching export in /design-reference. If a screen has no reference, say so and ask. Do not invent a layout.
- Use the design tokens (black #000000, card #0D0D0D, white, #F5F5F8, accent gradient #243100 to #DBEF90, Urbanist only, 24-32px radii, pill buttons). Max 4 stat cards per light section. Pink gradient only once per screen.
- No serif fallback fonts, no icon names rendered as text, no wrapped nav or balance pills, no empty sections.
- Pages must call the real API. No hard-coded arrays or fake numbers. Placeholders must be visibly marked and hidden in production.
- Before reporting a screen done, take screenshots at 1440 and 390 px and compare with the reference. List the differences you see.
